# Largs Colts 2016s App - Coach Testing Guide

This is a test version of the Largs Colts 2016s team app.

The aim is not to check the technical side. The aim is to use it like a coach would on a normal week and tell us what feels right, what feels confusing, and what is missing.

## What We Need Coaches To Test

Please try to test these areas.

## 1. Logging In

Check that you can:

- Log in using the coach account provided.
- See the coach version of the app.
- Sign out and sign back in.

Tell us if:

- Login is confusing.
- Any wording does not make sense.
- You are shown parent-only screens by mistake.

## 2. Home Screen

Check that the home screen gives you a clear quick view of:

- Next fixture or training session.
- Player numbers.
- Availability numbers.
- Pending parent requests.
- Quick coach actions.

Tell us if:

- The home screen feels useful.
- Anything important is missing.
- The buttons are easy to understand.

## 3. Fixtures And Training

Try to:

- View all upcoming fixtures and training.
- Add a new match.
- Add a new training session.
- Edit a match or training session.
- Remove a test match or training session.
- Use the venue options.
- Try an away venue by typing the address.
- Check the Google Maps and Apple Maps buttons.

Please check:

- Kick-off time.
- Report time.
- Finish time.
- Home kit / away kit.
- Venue address.
- Notes.

Tell us if:

- Creating a fixture is easy.
- The wording is clear.
- Any detail is missing for parents.
- Removing or editing an event feels safe enough.

## 4. Player And Squad Lists

Try to:

- View Orange, Blue and Yellow squads.
- Check the player names.
- Add a test player.
- Edit a player.
- Move a player between squads.

Tell us if:

- Any player is missing.
- Any player is in the wrong squad.
- The squad page is useful for coaches.

## 5. Parent Verification

This is one of the most important parts.

Try to:

- Open the Access page.
- View pending parent requests.
- Choose the correct child for a parent.
- Approve a parent request.
- Reject a request if it looks wrong.

The idea is:

- A parent creates an account.
- A parent asks to be linked to their child.
- A coach checks the request.
- A coach approves it.
- The parent can then only see their own child.

Tell us if:

- The process feels clear.
- You would know when to approve or reject.
- The app needs more information before approving parents.

## 6. Availability

Try to:

- Pick a match or training session.
- See who is available.
- See who is unavailable.
- See who has not replied.
- Check any notes from parents.

Tell us if:

- The availability list is easy to read.
- It helps with planning teams.
- You need filters, totals, or a different layout.

## 7. Attendance Register

Try to:

- Select a training session or match.
- Mark players as Present.
- Mark players as Absent.
- Mark players as Collected.

Important:

When a player is marked Present or Collected, the parent notification system is meant to send an app notification to the parent.

Tell us if:

- The register is quick enough to use at the pitch.
- The Present / Absent / Collected buttons make sense.
- You would want any extra options.

## 8. Messages And Announcements

Try to:

- Send a message to all teams.
- Send a message to one team colour.
- Check that the message appears in the app.

Examples to test:

- Training cancelled.
- Match venue changed.
- Reminder to mark availability.
- Bring away kit.

Tell us if:

- The message tool is simple enough.
- You need attachments, photos, or longer notes later.

## 9. Coaches Page

Check that the coaches page shows:

- Correct coach names.
- Correct phone numbers.
- Call and text buttons.

Tell us if:

- Any number is wrong.
- More coach details should be shown.

## 10. Phone Testing

Please test on a phone if possible.

Check:

- Does the app fit nicely on the screen?
- Are buttons easy to tap?
- Is the text readable outdoors?
- Can you install it to the home screen?
- Does it feel like an app rather than a website?

Tell us:

- Which phone you used.
- iPhone or Android.
- Anything awkward or slow.

## What To Report Back

Please report:

- Anything that does not work.
- Anything that is confusing.
- Anything that takes too many taps.
- Any missing football detail.
- Any safeguarding/privacy concern.
- Any wording parents might misunderstand.

Helpful examples:

- “I tried to add a fixture and could not find the report time.”
- “I approved a parent but they still could not see the child.”
- “The attendance buttons are too close together on my phone.”
- “The app needs a way to show cancelled training.”

## What This Test Is For

This test is to check whether the app works for real coach use before parents are invited properly.

Please do not add real parent contact details yet unless the club has agreed the privacy and consent wording.

Use test data first. Once the coach side feels right, we can move to a small parent test.
